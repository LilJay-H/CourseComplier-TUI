# Execution · 长课与续写

## 先全局、再局部

先浏览整堂课的教学路线与结尾通知，标出同对象的后续更正；再按 authoring 的教学单元逐一读材料、看对应 PPT、组织图文。不要只读开头结尾，不把音频/VAD 切块当作成文段落。

跨块携带未完成句子、指代、开放问题、术语、有效条件及未决事项。读到明确更正后，更新所有受影响模式及 Complete 层，而不是在末尾加一句话、前文继续保留过期要求。后来重提同一观点可能承担新的教学作用，不能一律去重。

## 输出预算与分工

根据任务实际可用上下文和输出空间，考虑所选模式、图注/步骤、Complete 细节和逐字层的总量，不只看转写长度。未知模型预算不能假报精确 token 或百分比。预留整稿校对和结束简报空间。

每轮优先完成一个连贯单元，避免同时开启所有模式却没有一份能完成。可以复用已经核对的事实与图文计划；写法按各 mode 独立，不通过缩短后半堂课来凑进一次回复。summary 省略旁支的权限不向 full/deep/complete 传播。

## 到达边界时怎样暂停

在完整句子/单元结束处停下，明确哪些源范围和哪些模式尚未完成。将可恢复的片段与单元状态保存到 authoring 许可的记录，或在网页回复中交付独立续写卡。字段至少涵盖任务标识、已处理源范围、每模式草稿、下一单元、未回答问题和待传播更正。

局部片段不能当作完整 expected_outputs 发布；恢复时先读原任务、同任务续写卡和必要源段，核对已有完整成品后再接续。不要重新生成已完成稿，不把续写卡的状态声明视为语义证明。网页可先按章节交片段，但最终必须合并核对为完整文件，不能要求用户猜拼接位置。

普通退出时应用可保留通过安全检查的记录；强制杀死、断电或尚未保存不保证恢复，不假称已经实现持续自动检查点。无法读取全附件或原课部分确实缺失时报告实际边界，不以“完整”命名消除缺口。

最后核查开头、中段、结尾、复杂单元与所有更正；删除内容为空的课堂噪声不等于遗漏，但应与未处理知识段区分。
