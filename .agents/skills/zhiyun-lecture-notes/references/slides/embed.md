# Slides · embed

本次允许读取 PPT 并在正文嵌图。按本次模块计划中的 `slides/reading.md` 完成内容识别、匹配与有意义页面覆盖，按 `slides/layout.md` 选择居中尺寸和组图。

- 尽量使用在本模式范围内有独有教学作用的 PPT，不设每章/全课固定图数；无信息重复可去重，重要中间步骤不能省略。简单考核等纯文字信息可转为一处完整文本框而不重复截图。
- 图片放在对应局部讲解上方。图承担已有的表示/结构/状态，文字解释图中欠缺的步骤、原因、条件与结论，避免整页复抄或仅写“如图”。
- 只引用本次真实、已检查的图片，使用任务给出的图片路径（云端任务为 images 中的 markdown_path；本地 `notes/` 下的稿件通常为 `../slides/images/<filename>`）。
- 有确切并列/顺承关系才用两图、三图并排或四图 2×2；内容稀疏的单图可居中半宽/三分之一宽，清晰度优先。具体语法只在 layout 模块维护。
- 图片与讲解的时间对齐（本地 `slides/alignment.json`、云端 slide_events）仅是时间重叠，不是语义认证。核对对象、符号、方向、状态和附近讲解，再写图注；回翻保留，缺图/未读图不伪造。
- 图与对应讲解共享章节/必要小节来源框，不在每张图后重复来源按钮。仅补图任务只添加图和必要图注，不借此改写原正文。
