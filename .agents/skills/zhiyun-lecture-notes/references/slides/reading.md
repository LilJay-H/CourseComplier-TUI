# Slides · 内容识别、匹配与信息覆盖

PPT 是课程证据，也可以承载讲义的信息，不是装饰。先读图和对应课堂材料，再决定哪些内容用图、哪些用文字；本模块不授予嵌图权限，是否插图仍由本次 source-only / embed 策略决定。

## 1. 先识别内容，不按页码猜主题

按课堂教学单元分批查看本次允许使用的全部 PPT，结合转写与实际展示事件，识别每页的概念、对象/符号、例子状态、操作方向、条件及与相邻页的关系。可以先用缩略概览定位，再打开原尺寸核对，但概览、文件名、上一份讲义的图注和 OCR 文本都不等于已经读过图。图内小字、箭头和中间状态看不清时必须回看原图；没有视觉能力/原图时标记未审阅，不虚构识别结果。

`alignment` 和展示时间仅提供候选范围，不证明语义对应。相同主题中仍要区分定义与例子、操作前后、同类操作的不同情形、不同对象及教师回翻；不能把同页名或时间最近当作匹配完成。回翻到同一图片的不同讲解必须在各自源范围中保留，不能因图片去重丢掉新解释。

在内部编辑记录（只用于自查；单次生成时在内部完成即可）中为已审阅页面/过程组记录：真实来源标识、承载的信息、对应教学单元、采用方式及必要取舍理由。采用方式包括插图/组图、信息转为文本、无信息增量的重复、无关或装饰、未读/缺图。仅路径存在不能算“已审阅”；记录只供覆盖核查，不另行写入未获授权的文件，也不写进成品或把审阅清单塞进学生正文。

## 2. 尽量覆盖有意义的 PPT，而不是抽几张代表图

启用嵌图时，full/deep/complete 对本课有独有教学作用的结构图、例题、过程状态、比较、图表、关键定义/公式页应尽量全部使用。不要预设每章一图、全课固定数量或每隔几页取一张。summary 按其速览范围选核心图；verbatim 不因加图删改有意义的原话。

每个有独有信息的页面都应有内容去处，不等于每张截图都必须重复展示：

- 结构、空间关系、流程或案例图：优先保留原图，并给出其对应讲解。
- 过程/动画拆页：保留操作前、关键中间步、结果；极相似的两页也可能新增了决定性箭头、数值或条件，不能仅凭外观近似删掉。反之，完全没有新信息的翻页不必重复展示。
- 定义、公式、关系总览：图中已完整呈现时可由图承载原表示，正文解释对象、变量、适用条件和理由；不能为了少插图把原有图示改成长段复述。
- 简单考核方式、截止时间、联系方式等：用一处可搜索、可复制的文本框/表格忠实呈现通常更清楚，不必再加同内容截图。主体、数值/单位、范围、情态、例外和有效更正不能丢。复杂评分结构图仍可保留在对应位置，文字重点解释层级而不重复抄表。
- 纯封面、空白页、无新增信息的目录、装饰：可不展示；有课程信息就提取到应在的位置，不把删除截图等同于删除信息。

PPT 与口述不一致时按 evidence 模块核对来源和明确更正；没有充分证据就保留冲突，不能因为图漂亮/文字完整而默认 PPT 最终正确。仍展示被更正的原页时在附近提示适用的更正，不能把它单独作为现行规则。

## 3. 图文互补，而不是图下注释或把图全文抄一遍

先确认“图已经讲清什么、读者还需要理解什么”。图承担结构、状态、表示或事实总览；文字补足阅读方法、每步变化、为何可行、条件、结论及易混点。定义/重要公式可因推理或可检索性在正文简短重述，但不逐条照抄整页再添一句“如图”。

案例优先按实际图/子图标识讲解：初始条件 → 这一步的操作对象和动作 → 状态如何变化 → 原因/保持的性质 → 结果；只展开源内确实支持的步骤，不给图中没有的状态或未讲的证明编故事。并列图用同一比较标准；顺承图明确先后顺序。不能只写“左边的移到那边”“看图就懂”来回避关键步骤。

full 仍保留有意义的课堂提问、推演、提醒和个人意见；deep 把这些组织成保持原课内容与顺序、直接可学的图文讲义，不固定套“课堂论证梳理”。complete 的主体按 deep，额外课堂细节和转写按单元展开，不能把理解主线必需的图藏起来。嵌图时图文位置按 slides/layout。图片与讲解共同可用即可，无需强迫正文独立重建整张图，但关键条件与必要推理不得缺失。仅补图任务遵守原正文只读范围，不借机压缩、改写或重排正文。

## 4. 交付前检查

结合 common/teaching 检查成品而非图片数量：多张图集中出现却只有一段泛泛概述，应回到实际状态和操作组织局部讲解；“图中就是这样”不能替代理解必需的联系。图注声称的主题与所在单元不一致时，重新回看原图和来源，不能编一个牵强理由解释摆放。这里只规定检查，不授权凭图注、文件名或文字统计自动认定匹配正确。

逐个教学单元核对：重要图是否遗漏、真实页与讲解是否匹配、过程是否缺关键步、只转为文本的页面信息是否保全、正文是否补足了图片欠缺的解释。说明未审阅/不可读的范围，不用图片数量、审阅记录或结构测试冒充语义已验证。
