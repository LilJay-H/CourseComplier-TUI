可以读取 PPT 来核对术语、公式、图示、名称和讲课结构，但最终 Markdown 不嵌入幻灯片图片。实际内容识别与匹配按所选的 slides/reading 模块执行；其中的嵌图建议不改变本次只参考的策略。必要信息用文字和共用来源映射如实表达；不要输出图块或待补图占位来替代这一不嵌图选择。

- 幻灯片证据确实有帮助时，用它消解明确的 ASR 歧义。
- 幻灯片时间对齐（本地 `slides/alignment.json`、云端 `slide_events`）只是时间重叠，不要称为语义精确。
- 教师回翻可能让页码变小。保留实际时间顺序，不强行让页码单调递增。
- 缺失或未知的幻灯片事件仍记为缺失或未知。
- 声称经 PPT 确认前，先查看实际页面；讲义中的引用或文件名不能替代。基于来源的解读同时注明实际页面和所用的发言，保留未解决的前提，不悄悄把某页幻灯片认定为最终规定。
