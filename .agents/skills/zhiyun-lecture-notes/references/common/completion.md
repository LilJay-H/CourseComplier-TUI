# Common · 成品验收

做两次方向不同的检查：先从原材料寻找成品缺失的内容（包括首次清单未抽出的整段主题），再从实际成品核对新增断言、数字、图注、归属及强制要求。前者的遗漏可以没有正文引句；后者不能只验证来源清单中的 Point。标题、图号、来源 ID、字符匹配或工作状态不能替代内容判断。

检查报告明确对象、方法、实际源/稿版本、范围及未评估项。没有相应记录，不写“全部严格验算”“已按标准核实”等自证结论。有效审阅发现不是程序故障：保留稿件与问题，有依据地局部修订并复核；不删题、删引号、减必要内容或扩大来源窗口来伪修复。

依据实际输入与成品检查，而不是复述规则。先按 common/teaching 的五个阅读问题检查真实成品；未评估或不适用不能记成通过，教学建议也不等于已确认的事实错误：

1. **内容**：起始、中段、结尾与难单元是否处理；动机、必要步骤、例子、条件与更正是否保留。读取全部 ID、篇幅足够都不能证明无遗漏。
2. **事实**：逐项核对行动对象、数值/单位/分母、范围、情态、例外及后续更正；检查知识中的限定和个人观点未升级成定理，编辑核验/外部补充与源材料分开。
3. **模式**：verbatim 原话身份正确，full 保全课堂展开，deep 是连贯教程，summary 的重点有依据、讲到能看懂且没丢前提；Complete 收起后保留核心动机/推理，细节有增量，逐字层逐块对照源句与行范围。标题的方向、主文与折叠中的数值和限定同样要核对；编者验算不写成课堂台词，语义重合不自动当作冗余。
4. **图文与阅读**：按 reading/layout 检查有意义页面去处、实际匹配、局部位置、图注和清晰度；按 presentation 检查常显行动、章节来源和整体折叠待核对。没有实际读图/渲染就不能宣称已验。
5. **交付**：每个 expected_outputs 真正完成，资源有效、不含凭证或另一课程内容，旧文件未改变；HTML 状态按 delivery。未完成片段存入许可的记录，不当作完整稿。
6. **恢复与复核**：记录实际处理范围、各模式状态、未处理单元和待传播更正。待核对必须指向具体缺口，不用“ASR可能有错”替代已发现的冲突。结构/引用字符检查、编辑自检、模型实际生成、读者评审分别报告；不存在的证据不补造。

另行检查：对 Deep/Complete 先收起折叠阅读，不能靠隐藏层弥补主文缺少的必要连接；不能用图注或“继续计算”略过材料已提供的关键步骤。标题、速览、主文和折叠答案中的日期、条件、数值是否一致；例题是否写出最终答案；引用是否截成缺少上下文的半句话。确需合并相邻转写段时保留准确来源范围，解释放在引用之外。公式不能含异常控制字符，表格不能丢失尾列，中文正文不能误入数学节点，代码示例不能作为公式执行。未请求 HTML 就记录未请求，不擅自生成，也不据此判失败。

结束只简报实际路径、处理范围、未决高风险项和待导出状态。记录与成品内容都必须据实；任何自动测试都不替代真实讲义的语义验收。

长课必须逐个教学单元对照原材料核查，不以主题相似、段数、字数或 ID 出现率代替覆盖判断。
课堂叙事、作品讨论、师生问答和组织活动若承担例证或推进作用，也是 Full 的有效内容。
一个后续术语相同的概括不能抵消前面整段案例的缺失。记录每个单元实际保留的位置或有依据的排除原因；
核查起始、中段和结尾之外，单独回查主题转换前后的连续段落。长课不能因预算不足悄然改成摘要。

来源身份逐条区分：老师口述、课件可见、编辑推论、待核对。课件上的数字或作品名可以引用，
但没有同期口述证据时只能称“课件列出”，不能编写“老师说”。断裂 ASR 中的作者、作品、数值
归属无法确认时保留具体疑点，不靠上下文猜测升级成确定事实。原始转写与课件标识须来自输入；
不知道客户端实际文件名时用材料类型与有效时间/段落/页标识定位，不编造文件名。
