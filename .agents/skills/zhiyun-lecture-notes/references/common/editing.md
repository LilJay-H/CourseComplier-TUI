# Common · 编辑、校勘与补充的边界

书面化不得改变对象、范围、条件、否定、情态、时间、发言归属及论证的让步/转折。建议额外实验不是必须理论证明，人工观察不是平台自动检测，本组结果不是普遍最优，本节教学子集不是整个标准。文字可以更清楚，不能比依据更肯定。

多个讲者可合并共同结论，但各自的实验设置、实现经验和独有论据仍须保留身份。教师、学生汇报、课件可见、编者推导和外部核验不能混为“老师指出”；未经回听不得确定归因于教师口误或 ASR 错误。组别、时间、参数无法确认时明确未知，不替现场消除歧义。

| 类型 | 可以做什么 | 怎样呈现 |
| --- | --- | --- |
| 语言整理 | 去无意义口癖、改病句、自然分段、明确有唯一依据的指代 | 正常正文，不逐句写“编者整理” |
| 源内教学化组织 | 把实际转写/PPT 已给出的对象、条件、步骤和结论连接清楚 | 保留原教学路线与全部限定，不增添新前提 |
| 编辑核验 | 检查算术、初值、方向、单位或源内相互矛盾 | 区分“发现问题”与“确定改法”；记录原文和核验依据 |
| 新推导或补充 | 原课未给的证明、背景、新例题、外部资料 | 仅在任务允许时加入，明确编辑者/外部来源身份 |

来源是写作依据，不是完美教材。不得默默把错误、争议或不清晰内容替换为记忆中的知识。明确的同对象后续更正可传播为有效结果；内部自洽检查可以发现矛盾，但不自动证明哪一句是教师本意。能够确定的技术校勘单独说明依据；无法确定时保留支持的内容与具体缺口，不强行补齐。

“只据材料”不妨碍把材料已经给出的推理关系写清，也不要求每句都带审查口吻。基础算术与条件的一致性核验按 common/teaching 执行：可明确报告可复算的冲突，不能据此擅改原话、宣布讲者已订正或补出其真实意图。源内重组不冒充新证明，归纳后的判断不能强于前提。教师的个人观点、经验、推测与未证直觉保留归属；已核对的通用说明直接解释即可。讲者的设问或假设（“如果有人说”“你可能会问”）属于讲者本人，不写成学生发言或真实问答；只有转写中确有他人发言或讲者明确点名回答时，才写“有同学”。同一组数字在不同来源（课件不同页、课件与口述）被归给不同对象时，保留各自来源并列入待核对，不默默统一。

重要行动的对象、动作、数值/单位、范围、建议/必须/禁止/暂定、例外和更正关系不能改变。第几次课不等于第几周，“最好”不等于“最迟”，“不能携带”不等于“不能用于查阅”。低风险已解决口误留在编辑记录；影响行动或核心理解的差异就地短提示，详细依据放入共用来源/待核对层。
