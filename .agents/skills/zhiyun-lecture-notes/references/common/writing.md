# Common · 学生阅读正文

输出 UTF-8 Markdown。语言目标是清楚、连贯、具体，不是执行日志或夸张的教材宣传。

- 自然段围绕一个微主题，把相邻转写碎片先合成完整意思；不按 ASR/VAD 边界机械分段。
- 保持术语和符号一致。口癖只有在无信息量时才删除；否定、不确定性、指代、条件和教师立场不能随之消失。
- 概念用连贯段落解释，真实过程才编号，平行关系才使用表格。避免一长段塞多个不同学习任务，也不要每句话单独换段。
- 数学步骤用显示公式、分行或对齐表达；不要把源码中的软换行误当作可见公式结构。数学和 HTML 的具体语法按 presentation，图块按 layout。
- 去除无信息的“颠覆性、铁律、绝对锁定”等声势词及机械点评，但保留源材料必要的技术术语、观点身份和限定。
- 正文不暴露处理统计、机器路径、工具对话。核验依据放在共用来源或待核对层，只有影响理解/行动的疑点就地提示。

顺序、前置行动框、课程信息和折叠仅由 common/presentation 规定；各模式编辑目标只看 modes，补充与校勘看 common/editing。源内讲解是否形成可跟随的连接、基础数值与前提是否核对，统一依 common/teaching；不要另加一套字数、公式数或固定章节模板。
