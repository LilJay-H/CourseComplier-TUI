# Common · 源内教学组织与基础核验

本模块适用于所有学科；只在材料涉及的维度执行，不要求人文讲义添加公式，也不要求无图任务补图。没有字数、图片数、公式数或固定章节模板的合格线。

## 先组织理解，再决定层次

内容取舍先后：本课核心定义、条件、方法、实际展开的例题和教师要求；本课独有的实现经验、实验反差、反例、讨论及更正；理解这些内容必需的衔接；最后才是任务明确允许的补充。不要删掉难整理的课堂内容，再用熟悉的教材背景填满篇幅。Full/Complete 的细节层保全有效增量，Summary 的压缩权限不能传播到其他模式。

先沿原课路线识别本单元要解决的问题、已给的对象与前提、关键变化或推理连接、例子及其结论。把材料已有的关系讲清，不以“继续展开”“标准计算”“如图可知”替代理解必需的步骤；材料确实没有的步骤应说明缺口，不能编造证明、设计参数或现场对话。

Deep 与 Complete 常显层直接面向学生解释知识，不默认逐句报道“老师接着说了什么”。这是叙述职责，不是禁用教师归属：个人观点、经验、推测、课堂承诺和争议仍须说明是谁的说法。Full 保全有信息的课堂展开；Summary 选取有依据的重点并讲到能看懂，可以省略旁支，但不能删除关键前提、纠正或行动条件。

Complete 写完后收起所有细节再读一遍：主线的问题、前提、必要推理、核心例子和有效结论能否独立连起来？不满足时，把必要解释放回常显层，而非靠多加折叠掩盖。旁支、第二种尝试、额外问答和有归属的意见放在相邻细节中保留；不要为了主文整洁而删掉源内有效信息。原话层允许与主文语义重合，但不替主文承担教学说明。

图和正文共同完成理解：读者应知道图中看哪个对象、发生了什么变化、为什么与当前问题有关。根据实际信息密度选择尺寸或组图，不统一半宽，不凭文件顺序分组，也不把多张图连续贴在一段概述之后。具体位置与安全语法只依 slides/layout；没有实际图片就不能认证图文匹配。

## 基础核验始终执行，高级数学路由不是前提

有数值或关系时，逐项检查：数值和单位对应哪个对象、分母与基准是什么、单项/整批/稳定间隔是否混淆、时间减少与倒数定义的性能提高是否混淆。直接算式应重新代入计算，等号两边要在相同语义和单位下成立；不得把没有复算的结论标成“已核验”。

涉及数字表示、逻辑式或符号约定时，先写明材料采用的约定（取值范围、数制、运算含义），不把一种约定下的结论套到另一种。区分材料中的具体设计示例与普遍规律；材料没给的参数和限制不凭常识补齐。必要/充分、有限可达/极限趋近、代数代入关系/实际运行等待不得互换。

材料已解出的例题保留必要步骤与最终结果（含单位与近似程度），不能停在“代入即可”；讲者只布置未解、或题设不全时，写明“课堂未解”或缺哪项条件，不强行补答案。编辑自行验算与讲者原话分开标注；结果不一致时两者并存并提示，不静默改正。

例题保全按同一道题的身份核对：目标、题设、单位/约定、关键步骤、结果或未解状态都应能在成品找到。同主题的另一道题、题目标题或一张图不能抵消原题缺失；课件未讲题只能在允许时标为课件补充。校验定义后仍须独立复算其示例；机器码、位宽算法先固定位宽/符号/截断/初值/循环调度，再检验边界。采样只能给反例或有限测试证据，不认证一般证明。

解释“为什么只有某种方案”“规范必须如此”前，先核实这个前提及其适用范围。先确认前提，再解释原因，不能为源内疑点编出更有说服力的动机。独立求解只接收充分题设，不以待审答案为前提；同一次已看过答案的自检不能声称完成了答案隔离。

有变量、上下标或多步推导时，使用当前输出支持的数学定界符、显示公式与分行，解释关键变量和源内连接；纯文本算式不能因“读起来差不多”而省去必要的结构。需要 JSON 外层时，Markdown 里的反斜杠按 JSON 规则转义一次。无数学内容无需制造公式。

## 忠实记录不等于认可错误

先区分三件事：材料实际说了什么、这些文字在已声明条件下是否自洽、能否确定讲者原意。Complete 原话节选仅可调整空白，不适用独立 Verbatim 的 ASR 噪声、口癖、机械结巴或有依据同音词清理权限；独立 Verbatim 仍按自身模块轻清理，不是字符精确摘录。确定的算术或条件冲突在引用之外以“编辑核验/条件核对”说明依据。不能静默改写原话、补造“教师随后纠正”，也不能因引用真实就把错误升级成主文结论。无法确定时保留具体缺口，不用通用教材替换。

影响核心理解或行动的疑点就地短提示，详细来源可放文末待核对层；不能一边在主文断言正确，一边把相反条件藏在折叠里。仅做源内解释与基本一致性核验，不授予添加外部知识、新例题、新证明的权限。

## 交付前的五个阅读问题

- 教程与模式：成品是否完成本模式的阅读职责，而不是换了标题的其他模式？
- 推理与条件：必要连接和前提是否实际出现，缺口是否如实说明？
- 图文：实际图像是否支持旁边讲解，默认尺寸能否阅读？未看图不能答“通过”。
- 数学呈现：有无有效公式语法和清楚的步骤，不以公式数量评优？
- 来源与核验：源内原话、推断、已核验计算和未决冲突是否区分？

这些是阅读检查视角，不是固定输出栏目或必须追加的审核说明。结构解析、精确引用、字数和模型自评都不能认证整课语义。无法检查的维度记录未评估或不适用，不制造通过。
