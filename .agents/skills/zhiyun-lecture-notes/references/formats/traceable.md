# Format · traceable

保持 common/presentation 的 major section/必要小节共用来源框，不按自然段或图片加按钮。与 clean 的差别是展开后有更完整的信息点—证据映射、更正依据和原始时间精度；不是正文更像审计日志。

## 同源格式示例

与 clean 使用相同的合成材料 A，但把对应关系展开。以下只是 examples/sources 的摘录映射，不是当前课的时间或已看PPT声明：

```html
<details>
<summary>本章时间与来源</summary>
<p>逐条落盘的瓶颈：ASR第1–2行；批量与次数降为1/K：3–4行；学生提问与断电丢失：5–6行；等待间隔K→K−1的更正：7–8行；双条件触发：9行。时间未提供，未回听音频，未核对原图。</p>
</details>
```

实际任务有 segment、回翻事件或可靠时间时保留它们的完整精度和对应关系；非连续来源分别列出，不合成一个虚假的连续区间。缺失、未读和不适用明确区分。疑点及完整证据仍置于整体关闭的待核对中，影响行动/理解的提醒继续常显。详细不等于重复每段的同一份来源，也不泄露私有路径。
