# Format · clean

以连续阅读为主。通用外壳、来源聚合与关闭状态只按 common/presentation；本模块只决定展开后的信息密度，不重新规定框的数量或位置。

来源折叠内用简明时间与出处，保留关键更正依据；精细机器索引不进入正文。实际时间可显示为便于阅读的秒级范围，原始精度保留在引用记录；未知时间如实标明，不能用近似时间冒充精确值。正文与折叠标题不显示内部路径、seg/occ编号或处理日志。

## 同源格式示例

以下用 examples/sources 的合成材料 A，不是当前任务信息；缺少时间索引，因此不补造时间：

```html
<details>
<summary>本章时间与来源</summary>
<p>据所给ASR第1–9行：逐条落盘的瓶颈、批量的收益与代价、双条件触发；等待间隔采用第8行的当堂更正。该材料未提供时间，未经音频核验。</p>
</details>
```

上面的简明出处由本任务真实材料替换；不能把示例行号复制到新课程。正文不因 clean 而删除重要条件、行动风险或可查来源。
