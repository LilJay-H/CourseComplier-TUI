# 合成教学编辑对照（不是本课材料）

本页为人工编写的短示范，只学习编辑方法。这里的过滤器、符号、原话和层次均不是当前任务的证据；不要复制到无关课程，不编造来源行号或图片。未给的证明和参数不补造。

## 同源对照：条件应进入解释，而不是只留公式

**合成来源**：起初有 N 条记录。第一步保留其中比例 p；第二步只处理第一步剩下的记录，并保留其中比例 q。所以第一步后是 Np 条，第二步后是 Npq 条。q 的分母是第一步剩余量，不是原始总量。另有讨论者说，每个过滤岗位只看到自己的一步可能不利于了解全流程，这是个人观点。

**不足的写法**：老师先说N，然后老师说p和q。两步过滤就是Npq，继续计算即可。讨论者说只做一步不懂整体。

问题不在“老师”出现了几次，而在关键分母和两步数量如何衔接都没讲；删除教师称谓本身不会解决这个问题。

**Deep / Complete 常显正文的写法**：

第二步的保留比例作用于第一步的输出，因此需要先确定中间数量。第一步从 N 条记录中留下比例 p：

$$N_1 = Np$$

第二步的输入是这 Np 条，而不是原来的 N 条；再保留其中比例 q，得到：

$$N_2 = N_1q = Npq$$

这里不能把 q 解释为相对原始 N 的比例后仍直接沿用同一推导，必须保持来源给定的分母约定。

**相邻细节层的职责**：保留“分工可能影响全流程理解”的观点和归属；不要把上面的两条公式换一种说法再抄一遍，也不能因为移入折叠就把观点写成事实。原话层只有找到当前任务真实转写后才摘录，不能把上述教程改成第一人称。

## 同源错误记录不等于正确结论

**另一组合成来源**：记录写下“8加7等于14”，没有后续订正。

可保留这句记录，但如需引用应按实际来源范围摘录；不能改成“8加7等于15”后称为原话。正文可明确写“编辑核验：按通常十进制加法，8+7=15，与此记录的14不一致；无法仅凭记录确定讲者原意”。这个核验只说明算术冲突，不许可编造“教师已纠正”或把任务其他不明信息一起修正。

## 常见失误对照（以 examples/sources 的合成 A、B 为例）

以下每组都是“不足的写法 → 问题 → 改写”。它们概括的是生成讲义中反复出现的问题，内容为合成。

**1. 折叠细节补造场景与背景。**
不足：“教师在批改往年作业时指出，很多同学误以为断电不会丢数据，这是严重错误！”
问题：来源 A 第5行只是“有同学问”，没有批改作业、往年或“很多同学误以为”；感叹号也没有信息。教材版本、历史典故、“可减少九成”之类的数字，来源里没有就不能写。
改写：“这一点由学生提问引出：攒的过程中断电怎么办？教师回答尚未落盘的那一批会丢失。”

**2. 提高确定性，或丢掉具体行动。**
不足：“教师明确宣布下周进行小测，成绩计入平时分。”
问题：A 第10–11行两处都是“可能”，没有说计分方式，而且原话要求“带好纸笔”。
改写：“下周可能有小测，带好纸笔。”

**3. 行动框写成知识点总结。**
不足：在 `[!IMPORTANT]` 里列出“批量落盘原理（必考）”“等待公式（核心考点）”。
问题：行动框只放作业、测验、考核等行动；源内没说“必考”，就不能加这类标签。知识点放正文。

**4. 用声势词代替说明。**
不足：“批量落盘实现了吞吐的极致飞跃，完美解决了积压问题！”
问题：读者得不到任何数量关系；“完美”也不对，因为批量带来了等待和丢失的代价。
改写：“落盘次数降为原来的 $1/K$，代价是最早一条最坏多等 $(K-1)\Delta$。”

**5. 把汇报或个人观点写成课程结论。**
不足：“本课指出，地方志报喜不报忧。”
问题：这是 B 中学生小组的暂定判断，教师随即提醒要谨慎。
改写：“小组据此认为县志在这件事上可能报喜不报忧；教师肯定了对照方法，但提醒迁走也可能另有原因。”

**6. 计算只写在图注里。**
不足：正文只写“批量能提高吞吐”，图注写“逐条 5000ms/秒，批量 K=5 时降到 1000ms/秒”。
问题：读者收起图片或看不清图注就失去了全部推导；图注不是正文。
改写：正文写出 $1000 \times 5\ \text{ms}$ 与 $5000/K$ 的推导和结论，图注只写“逐条与批量两种时间线”。

**7. 题外话常显、核心辨析藏进折叠。**
不足：正文用一大段讲讲者对某厂商的评论，而“批量为什么不是越大越好”只出现在折叠里。
问题：主次颠倒。讲者自己说明是题外话的内容属于细节层；课程要学生掌握的辨析必须常显。
改写：正文讲清批量的代价与双条件；评论放进课堂细节折叠并保留“讲者认为”。

**8. 小节末尾连续堆图。**
不足：先写完整节文字，再在末尾并排或连续放四张图。
问题：读者无法把图和对应解释对上。
改写：每张图紧贴它所对应的那段解释；确属同一比较的两三张图才用一个组图。

**9. 给题外话加标签，却仍放在正文。**
不足：正文写一个小标题“产业见闻（讲者标注的题外话）”，下面整段展开。
问题：加标签不等于放进折叠，读者仍要在主线里读完这段。
改写：Complete 把整段放进课堂细节折叠；Deep 省略或只用一句注明归属的结论；Full 就地保留一段并标明。

## 无图、无公式也可以是合格教程

若材料是历史记录、概念辨析或文本论证，按对象、证据范围和论证关系说明即可。不要为了模仿本示范硬添公式、过滤步骤或图片。来源依赖图示时，则必须回看实际图，并让图和解释在对应位置共同讲清内容。
